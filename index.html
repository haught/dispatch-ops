Dispatch Ops

Helm chart repository for the Dispatch Ops operator.

This page is the Helm repository for Dispatch Ops, a Kubernetes-native platform for running Ansible playbooks, scripts and container commands as jobs.

Add the repository

helm repo add dispatch-ops https://haught.github.io/dispatch-ops
helm repo update
helm search repo dispatch-ops --versions

Install the operator

helm install dispatch-ops-operator dispatch-ops/dispatch-ops-operator \
  --namespace dispatch-ops-system --create-namespace

The chart is also published as an OCI artifact: oci://ghcr.io/haught/dispatch-ops/charts/dispatch-ops-operator.
